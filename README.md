# Penance
*One final plea.*

Beaten down and defeated,  a man turns to his final hope: You.

This game was made for the [O2A2 VN Jam 2026](https://itch.io/jam/o2a2-2026), a micro Visual Novel jam with strict asset limitations and a 1000 word limit.



## Features

- ~950 Words
- 2 Endings

## Content Warnings

Contains blood and gore.
